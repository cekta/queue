# CEKTA/QUEUE

Пакет абстракции для очереди FIFO, который может иметь различные реализации:

* РСУБД
  * postgres
  * mysql
* in memory хранилища
  * redis
* Специализированные системы очередей
  * kafka
  * rabbitmq
  * beanstalkd

Также могут быть гибридные способы реализации, когда история задач и мета информация хранится в РСУБД, а сама очередь в 
in memory или специализированных решениях.
