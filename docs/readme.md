# CEKTA/Queue

Простейшая абстракция над очередью, которая позволяет выполнять действия в фоновом режиме.

Абстракция имеет простейший вид чтобы ее можно было просто реализовать в любой системе: 
РСУБД, kafka, rabbitmq, beanstalk, redis и тд.

## payload

Это результат jsonSerialize, полезная нагрузка задачи которая будет выполняться в обработчике (Handler)

## UUID

Это уникальный идетинтификатор задачи, ключ идемпотентности.  
Желательнг uuid v7

## Handler

Обработчик для Task.

## Task

Это абстракция над конкретной задачей которая возвращает информацию:
1. UUID
2. Status
3. Payload
4. CreatedAt
5. FinishedAt
6. StartedAt
7. FQCN
8. Handler

## Producer

Инструмент пользователя для постановки задачи в очередь.  
У каждой очереди свой producer, который ставит задачи в конец.


## TaskRepository

Инструмент для получения информации о задачах (в том числе выполненных)
